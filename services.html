How every line runs

The same three phases, whichever lines are engaged. Measured at each one.

PHASE 01

Diagnose

Four to six weeks. What the firm claims, what it can show, and the distance between the two. Ends in a written position, not a deck.

PHASE 02

Build

One to two quarters. The system is documented as it is built, so the deliverable is the documentation rather than a report about it.

PHASE 03

Calibrate

Ongoing, and optional. Everything is versioned like software, because that is what an operating model is.
