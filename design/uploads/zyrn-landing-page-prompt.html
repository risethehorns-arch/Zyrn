Exact build prompt — ZYRN landing page

Build this page pixel-faithfully. Stack: React + TypeScript + Vite + Tailwind CSS + lucide-react. Do not invent alternate copy, layout, fonts, colors, or effects. Where this document is silent, choose the quieter option — Zyrn’s design doctrine is instrument-grade restraint.

Page identity

  • Title: ZYRN — Organizations, Engineered
  • Brand: uppercase sheared ZYRN wordmark (custom component, spec below). No icon fonts, no hexagon.
  • Overall feel: dark instrument-grade precision site; full-viewport scroll-scrubbed video background; Vapor typography with subtle shadows; hairline-bordered panels (NOT frosted-glass blobs); mono metadata everywhere; one Pulse accent per viewport; the shear as the single signature device.
  • Doctrine (governs every ambiguous decision):
    1. Silence is the luxury — 80%+ of any viewport is empty or video.
    2. Metadata as ornament — the only decoration is real information (coordinates, indices, timestamps, version tags) set in mono.
    3. One Pulse per surface — #6E56F8 appears exactly once per viewport.
    4. The shear belongs to the logo only — never shear photos, headlines, or cards.

The ZyrnShear wordmark component (signature — build first)

A reusable <ZyrnShear /> React component. This is the identity; get it exact.

Structure: - Two absolutely-stacked copies of the text ZYRN (Space Grotesk 500, tracking 0.06em), each clipped to one half: - Top copy: clip-path: inset(0 0 50% 0) - Bottom copy: clip-path: inset(50% 0 0 0) - A seam line: absolutely positioned 2px tall div in Pulse #6E56F8, vertically centered, width calc(100% + 24px) (12px overhang each side), transform-origin: center.

Props: size (font-size px), progress (0–1, drives the shear externally), auto (boolean — self-animates on mount when no scroll binding).

Shear math (fixed law): - Max offset = 10% of font-size (e.g. 6px at 60px). Never more. - Top half: translateX(-offset * progress). Bottom half: translateX(+offset * progress). Always this direction. - Seam: scaleX(progress), opacity progress. - Transition when auto: 650ms cubic-bezier(0.83, 0, 0.17, 1), fires 300ms after mount, shears to progress = 1 and stays sheared (aligned = before, sheared = after; it never snaps back). - prefers-reduced-motion: render statically at progress = 1.

Monogram variant <ZyrnMark />: same two-half clip technique applied to a single Z glyph (SVG, stroke #F2F3F5, square caps) with the Pulse seam. Used as favicon, nav mark at mobile widths, and footer stamp.

Scroll system (elevated — this is where the immersion lives)

1. Scroll-scrubbed video (keep, tighten)

Fixed full-bleed z-0, overflow-hidden, pointer-events-none. Layers bottom→top: treated poster <img> → <video> (muted, playsInline, preload=auto, object-cover) → <canvas> drawing cached frames. Crossfades duration-500 exactly as the source prompt.

  • progress = scrollY / (scrollHeight - innerHeight) clamped 0–1.
  • Lerp factor 0.08 (was 0.12) — slower settle reads as mass and machinery rather than UI. Each rAF: smoothed += (target - smoothed) * 0.08.
  • Frame cache: offscreen video, up to 120 frames (or duration * 14, min 30), max width 1024px, extraction starts after visible video loadeddata + 300ms yield. Canvas draws ImageBitmap by smoothed index with object-cover math. DPR min(devicePixelRatio, 2).
  • Fallback: seek visible video to smoothed * (duration - 0.05) when delta > 0.04s.
  • Micro-parallax: canvas draw scale 1.0 + smoothed * 0.04 — an almost-subliminal push-in across the full scroll. Center-anchored.
  • No autoplay looping. Motion is scroll-driven only.

2. The shear is scroll-bound in the hero (signature moment)

The hero H1 lockup is <ZyrnShear size={heroSize} progress={shearProgress} /> where shearProgress = clamp(scrollY / 220, 0, 1), lerped with the same 0.08 factor.

  • At page top the wordmark sits aligned and whole. As the user makes their first scroll gesture, the halves shear apart and the Pulse seam draws itself left-to-right (scaleX origin-left for this instance).
  • Once progress reaches 1 it latches — scrolling back up does NOT un-shear (one-way hasSheared ref). The transformation happened; it does not undo. This is the brand narrative executed in scroll physics.
  • The nav logo <ZyrnShear size={20} auto /> self-shears on load, independently.

3. ScrollReadout (new — metadata as ornament, made live)

Fixed vertical rail, right-5, vertically centered, desktop only (hidden lg:flex), z-40, mono text-[10px] tracking-[0.16em] text-[#767E8C], writing-mode: vertical-rl.

Content: ZYRN / SYS.01 — {pct}% where {pct} = Math.round(smoothed * 100) padded to 3 digits (007, 042, 100). Beside it a 1px track h-24 in Hairline with a Pulse-colored fill scaling with progress — this counts as the Pulse instance for mid-scroll viewports (the hero’s Pulse is the seam; when the hero leaves view, the rail’s fill is the only Pulse on screen — enforce by giving the rail fill opacity: 0 until smoothed > 0.15).

The page tells you where you are the way an instrument does: with a number.

4. Reveal animation (sharpened)

IntersectionObserver, threshold 0.15, will-change: transform.

  • Hidden: translate-y-6 opacity-0 clip-path: inset(0 0 18% 0)
  • Visible: translate-y-0 opacity-100 clip-path: inset(0 0 0% 0)
  • Transition 700ms cubic-bezier(0.22, 1, 0.36, 1), per-element delay as specified per section.
  • The clip component makes text feel machined into place rather than floated in. Apply to text blocks and panels only — never images/video.
  • prefers-reduced-motion: all reveals render visible statically; scrub still functions (it is position, not animation) but micro-parallax scale locks at 1.0.
